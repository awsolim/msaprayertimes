# MSA Prayer Display

A full-screen web display for Muslim Students Association prayer times.

- Data source: https://msauofa.ca/prayer-times
- Goal: show today's prayer times on a monitor (Raspberry Pi 4) and allow access from laptops.
- The app will fetch prayer times once per day and display them in a non-scrollable layout.
- Future: rotating slides for events and adhkar, editable without changing code.
